# ninja-frog-2d

Proyecto de videojuego de plataformas en 2D desarrollado en **Unity**, correspondiente a la Unidad 1 de la materia de Creación de Videojuegos.

## Características
- **Personaje:** Ninja Frog (Pixel Adventure 1)
- **Mecánicas:**
  - Control de movimiento y salto con físicas 2D (`MovementController.cs`).
  - Nuevo sistema de entrada (*Unity Input System*).
  - Recolección de objetos (`RecogerObjeto.cs`).
  - Animaciones de movimiento, salto y reposo.
  - Obstáculos y trampas (Picos).

## Requisitos
- Unity (versión 6 / Unity 2022 LTS o superior).
- Paquetes: *Input System*, *2D Animation*, *2D Tilemap Editor*.
